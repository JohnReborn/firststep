# FirstStep: Learn to Invest by Doing

A web app that teaches Irish beginners to budget, save and invest with virtual money,
built around the Budget 2027 Investment Account. Information, not financial advice.

## Status
Sprint 1 in progress. See the [project board](link-to-board).

## Tech stack
Java 21, Spring Boot, MySQL, MongoDB Atlas, Spring AI, Firebase, Docker,
GitHub Actions, Google Cloud Run.

## Running locally
Coming in Sprint 1.

## How I work
Two-week sprints, GitHub Flow, every change through a pull request with CI.
